# MORECO — Downloadable Benefit Forms Guide

How to add PDF application forms to the Benefits page so members can download and print them.

---

## How the System Links Forms to Benefits

Every benefit card on the Benefits page has a **📄 Download Form** button. When a member clicks it, the browser looks for a PDF file in this location inside your website folder:

```
moreco/
  assets/
    forms/
      form_1_regular_loan.pdf
      form_2_emergency_loan.pdf
      form_3_savings_program.pdf
      ...
```

The filename is automatically built from two things:
1. The **benefit's ID number** in the database
2. The **benefit title**, converted to lowercase with underscores

**Formula:**
```
form_{id}_{title_as_slug}.pdf
```

**Example:** A benefit with ID `1` and title `Regular Loan` expects:
```
assets/forms/form_1_regular_loan.pdf
```

---

## Step 1 — Find the Benefit ID

The ID is assigned automatically by MySQL when the benefit is created.

**For existing (seeded) benefits**, the IDs follow insertion order:

| ID | Benefit Name              | Expected Filename                        |
|----|---------------------------|------------------------------------------|
| 1  | Regular Loan              | `form_1_regular_loan.pdf`                |
| 2  | Emergency Loan            | `form_2_emergency_loan.pdf`              |
| 3  | Savings Program           | `form_3_savings_program.pdf`             |
| 4  | Share Capital Program     | `form_4_share_capital_program.pdf`       |
| 5  | Burial Assistance Program | `form_5_burial_assistance_program.pdf`   |
| 6  | Livelihood Support Program| `form_6_livelihood_support_program.pdf`  |

> **To confirm the exact ID**, open **phpMyAdmin** → select the `moreco` database → click the `benefits` table → look at the `id` column for each benefit.

---

## Step 2 — Prepare the PDF Form

1. Create or scan your application form in **Microsoft Word, Google Docs, or Canva**
2. Export or print it as a **PDF file**
3. Rename the file to match the expected filename exactly (lowercase, underscores, no spaces)

**Naming rules:**
- All **lowercase**
- Spaces become **underscores** `_`
- Remove special characters (parentheses, commas, accents)
- Must end in `.pdf`

**Examples:**
```
✅  form_1_regular_loan.pdf
✅  form_5_burial_assistance_program.pdf
❌  Form 1 - Regular Loan.pdf        (wrong — has capitals and spaces)
❌  form_1_RegularLoan.PDF           (wrong — has capitals)
```

---

## Step 3 — Upload the PDF to the Server

### Using XAMPP (local / development)

1. Open **File Explorer** and navigate to your XAMPP folder:
   ```
   C:\xampp\htdocs\moreco\assets\forms\
   ```
2. Copy your renamed PDF into that folder
3. Done — the download button will work immediately

### Using cPanel / Web Hosting (live server)

1. Log in to your hosting **cPanel**
2. Open **File Manager**
3. Navigate to: `public_html/moreco/assets/forms/`
   *(or wherever your moreco folder is hosted)*
4. Click **Upload** and select your PDF file
5. Done

### Using FTP (FileZilla or similar)

1. Connect to your server via FTP
2. Navigate to: `/public_html/moreco/assets/forms/`
3. Drag and drop the PDF from your computer to the server folder
4. Done

---

## Step 4 — Test the Download Button

1. Open the MORECO website in your browser
2. Go to the **Benefits** page
3. Find the benefit you just added a form for
4. Click **📄 Download Form**
5. The PDF should download or open in a new tab

**If the button does nothing / shows an error:**
- Double-check the filename spelling (it must match exactly)
- Make sure the file is in the correct folder: `assets/forms/`
- Check that the file extension is `.pdf` (not `.PDF` or `.docx`)

## When You Add a NEW Benefit

When you click **➕ Add Benefit** in the Admin Panel and save a new benefit:

### Step 1 — Find the new benefit's ID

After saving, go to:
- **phpMyAdmin** → `moreco` database → `benefits` table
- Look at the last row — that is your new benefit
- Note the `id` number (e.g., `7`)

### Step 2 — Name your PDF

Convert the title to a slug:
```
Title:    "Calamity Loan"
Slug:     calamity_loan
Filename: form_7_calamity_loan.pdf
```

**Quick slug conversion rules:**
- Lowercase everything
- Replace every space with `_`
- Remove: `( ) , . ' " /` and other symbols
- Keep letters, numbers, and underscores only

### Step 3 — Upload the PDF

Place `form_7_calamity_loan.pdf` in:
```
moreco/assets/forms/
```

The **📄 Download Form** button on the Benefits page will immediately link to it.

## Optional: Set a Custom Form URL

If you want to use a different filename, a Google Drive link, or a URL from another server, you can set a `form_url` directly in the database:

1. Open **phpMyAdmin** → `moreco` database → `benefits` table
2. Click **Edit** (pencil icon) on the benefit row
3. Find the `form_url` column
4. Enter any URL, for example:
   - `assets/forms/my_custom_form.pdf` (local file, different name)
   - `https://drive.google.com/file/d/XXXX/view` (Google Drive)
   - `https://yoursite.com/forms/loan_form_2026.pdf` (external URL)
5. Click **Save**

When `form_url` is set, the system uses that instead of the auto-generated filename.
