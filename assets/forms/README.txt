MORECO Benefit Application Forms
=================================
Place downloadable PDF forms here using the naming convention:

  form_{benefit_id}_{benefit_slug}.pdf

Examples:
  form_1_regular_loan.pdf
  form_2_emergency_loan.pdf
  form_3_burial_assistance.pdf
  form_4_livelihood_program.pdf

These are linked from the Benefits page "Download Form" buttons.
The system will auto-generate the expected path from the benefit ID and title.

If a benefit has a custom form_url set in the database, that path is used instead.
